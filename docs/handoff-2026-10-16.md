## Flujo de trabajo (SIEMPRE seguir)
- **SDD por OpenSpec**: cada change = `openspec/changes/<name>/` (explore→proposal→spec/design→tasks→apply→verify→archive). Ejecutar vía subagentes `sdd-*`; el orquestador **no toca `openspec/**` durante apply** (lo reconcilia el archive).
- **Cadena de PRs** (`feature-branch-chain`): tracker branch → slices (TODAS las bases = tracker; mergear cada slice al tracker ANTES de la siguiente) → tracker → `develop`. `main` no se toca.
- **Rama nueva ANTES de editar**. Commits convencionales, sin atribución AI.
- **Gates**: `node --test "tests/js/**/*.test.js"` (~193) + `pytest` (~337 non-web + E2E dev-only `-m e2e -p no:randomly`) + `ruff check`/`format --check` + `makemigrations --check` + patch 100% (diff-cover vs `origin/develop`).
- **Push**: usar `GIT_TERMINAL_PROMPT=0` (el interactive cuelga).

## Gotchas aprendidos (críticos)
1. **Techo de 300 líneas por módulo JS** (`tests/web/test_module_size_guard.py`): `chart-host.js` 297, `controllers/drawings.js` 261, `drawing-interaction.js` 217. Extraer antes de agregar.
2. **`ColorType.Solid` / `PriceScaleMode` por SÍMBOLO**, nunca magic number.
3. **#68 single-write-path**: live WS → `update()`; history/config → `setData`. El drag re-renderiza por primitive `requestUpdate`.
4. **`for_user`** en todo acceso a modelos owned en el request path (guard R14.3). Lectura unscoped de owned models: SOLO en `web/worker.py` (R14.4).
5. **Migraciones destructivas**: orden SQLite-safe = RemoveIndex → AlterField(default) → RemoveField → AddIndex. Reverse puede ser lossy (documentar).
6. **CI corre Node 22** (local puede ser 24): usar literales exactos para floats (`Number("1e-"+n)`, no `Math.pow`).
7. **E2E flake clase C** (SQLite threaded live_server) — correr `-m e2e -p no:randomly` en máquina idle. CI NO corre E2E (`addopts = -m 'not e2e'`).
8. **verify subagente se corta** a veces (red); verificar el estado tras un fallo y completar inline con probes si hace falta.
9. `tasks.md` `[x]` lo marca el ARCHIVE, no el apply.
